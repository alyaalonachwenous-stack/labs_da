# Лабораторна робота 7: Computer Vision та багатопотоковість у C++

## Опис завдання
У цій лабораторній роботі реалізовано:
- Інтеграцію модуля OpenCV DNN для детекції облич за допомогою моделі ResNet-10.
- Багатопотокову архітектуру (Рівень 2 - Поглиблений) для усунення блокування графічного інтерфейсу (UI) важкими обчисленнями нейромережі.
- У фоновому потоці штучно додано затримку `std::this_thread::sleep_for(500ms)`, щоб наочно продемонструвати відсутність зависання відеопотоку.

### Архітектура системи (Multi-threading)
- **`FaceDetector`**: Клас, що інкапсулює нейромережу та керує фоновим потоком (`std::thread`). 
- **`std::mutex mtx`**: Використовується для безпечного доступу до спільних ресурсів (поточного кадру `currentFrame` та вектора знайдених облич `faces`) з обох потоків.
- **Main Thread (UI)**: Зчитує кадри з `CameraProvider`, передає їх копію в `FaceDetector`, малює отримані координати рамок та виводить відео (30 FPS).
- **Worker Thread**: Працює у нескінченному циклі `workerLoop()`, очікуючи нові кадри. Виконує `net.forward()`, записує координати та засинає.
